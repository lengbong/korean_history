# 🐯 범이의 역사 탐험대

아이부터 어른까지 가족이 함께 즐기며 배우는 한국사·세계사 학습 웹사이트예요.
호랑이 탐험대장 **범이**와 함께 선사 시대부터 오늘날의 대한민국까지, 피라미드부터 우주 탐사까지 시간 여행을 떠나요!

## 이렇게 놀아요

| 놀이 | 내용 |
| --- | --- |
| 🗺️ **한국사 탐험** | 9개 시대(선사 → 고조선 → 삼국 → 남북국 → 고려 → 조선 → 근대 → 일제 강점기 → 대한민국)를 정거장처럼 따라가며 이야기를 읽어요. 슬라이드마다 유적·유물·인물 **사진 3장**(큰 사진 1장 + 작은 사진 2장)이 함께 나오고, 사진을 누르면 크게 보며 설명과 출처를 볼 수 있어요. 끝까지 읽으면 **탐험 도장**과 카드를 받아요. 핵심 낱말 뒤집기 카드와 재미있는 사실도 있어요. |
| 🌍 **세계사 탐험** | 8개 시대(고대 문명 → 고대 제국 → 중세 → 르네상스와 대항해 시대 → 시민 혁명과 독립 → 산업 혁명 → 세계 대전과 평화 → 현대 세계)를 한국사와 같은 방식으로 탐험해요. 유럽·중국뿐 아니라 시대마다 **아메리카·아프리카·일본** 이야기도 들어 있어요(올멕·마야·아즈텍·잉카, 쿠시·악숨·말리·만델라, 조몬·사무라이·메이지 유신·신칸센 등). |
| 🧭 **나라별 세계사** | 세계사 탐험에서 **‘나라별로’**를 고르면 16개 나라(🇨🇳 중국 · 🇯🇵 일본 · 🇲🇳 몽골 · 🇬🇷 그리스 · 🇮🇹 이탈리아 · 🇬🇧 영국 · 🇫🇷 프랑스 · 🇩🇪 독일 · 🇷🇺 러시아 · 🇺🇸 미국 · 🇲🇽 멕시코 · 🇵🇪 페루 · 🇪🇬 이집트 · 🇮🇶 이라크(메소포타미아) · 🇮🇳 인도 · 🇹🇷 튀르키예)의 역사를 따로 볼 수 있어요. 나라마다 ‘벌거벗은 세계사’처럼 재미있는 **숨은 이야기 4편**(모두 64편)이 실제 유적·유물·그림 **사진**과 함께 나와요. 이야기는 🤔 궁금증 질문으로 시작하고, 💥 **반전! 알고 보니**(흔한 오해 바로잡기), 🔗 **지금 우리와 연결**, 🐯 **그때 우리나라에서는?** 상자로 끝나요. 🌱 쉬운 이야기 · 🌳 자세한 이야기 · 🎓 어른용 이야기(강의처럼 긴 이야기, 편당 약 2,200~2,700자·5분 안팎) 가운데 골라 읽을 수 있어요. 나라마다 한눈에 보는 연표와 **나라별 퀴즈**(모두 192문제)가 있고, 4편을 다 읽으면 🛂 **세계 여권 도장**과 그 나라 카드를 받아요. |
| 🎓 **어른용 깊이 읽기** | 한국사·세계사 탐험의 시대 이야기마다 **🌱 쉬운 이야기 · 🌳 자세한 이야기 · 🎓 어른용 이야기**를 골라 읽어요. 🎓를 고르면 슬라이드 62장마다 강의 한 편 분량(공백 뺀 1,500자 이상)의 해설이 나오고, 긴 글 사이사이에 그 슬라이드의 사진 3장이 끼어 있어 읽다가 숨을 돌릴 수 있어요. 시대마다 **⚖️ 쟁점과 학설**(해석이 갈리는 대목과 지금의 연구), **📜 사료로 읽기**(기록 → 행간 읽기 펼치기), **🌗 빛과 그림자**(성취의 이면) 상자가 붙어요. 카드 91장에는 평가와 논쟁을 담은 **어른을 위한 해설**이, 퀴즈에는 사료·인과·쟁점을 묻는 **어른용 문제 136개**(시대마다 8개)가 더해져 🎓 심화 대원에게 먼저 나와요. 고른 수준은 나라별 세계사에도 함께 적용돼요. |
| 📺 **영상으로 더 보기** | 시대 이야기(슬라이드 주제 영상 + 시대 전체 영상), 나라별 세계사 이야기, 한능검 개념 노트 단원마다 어른을 위한 강의·교양 유튜브 영상을 골라 붙였어요. 큰별쌤 최태성, KBS 역사저널 그날, EBS, tvN 벌거벗은 세계사처럼 공식 채널 위주예요. 누르면 그 자리에서 재생되고(유튜브 쿠키를 줄인 youtube-nocookie 주소), 누르기 전에는 유튜브를 불러오지 않아 페이지가 느려지지 않아요. |
| 🔗 **함께 보기** | 한국사 시대마다 **‘그때 세계에서는?’**, 세계사 시대마다 **‘그때 우리나라에서는?’** 상자가 있어 같은 시기를 비교할 수 있어요. (예: 직지심체요절은 구텐베르크보다 약 70년 앞서요) |
| ❓ **역사 퀴즈** | 한국사·세계사 각각 시대별 5문제 또는 모든 시대 섞어서 10문제. 세계사 퀴즈 화면 아래에는 나라별 퀴즈도 있어요. OX 퀴즈와 객관식 문제(모두 193개)가 나오고, 문제마다 해설이 나와요. 3문제 이상 맞히면 카드 1장, 만점이면 2장! |
| 🃏 **카드 도감** | 한국사 47장, 세계사 44장, 모두 91장의 인물·문화유산·상징 카드를 모아요. 카드마다 실제 초상화·유물·유적 **사진**이 붙어 있어요. 카드를 누르면 업적과 ‘알고 있니?’ 이야기가 나와요. |
| 🔢 **순서 맞추기** | 역사 사건 카드를 옛날 일부터 차례대로 놓아요. **한국사 / 세계사 / 섞어서** 중에서 고를 수 있어요. 모두 맞히면 보너스 카드! |
| 🎓 **한능검 심화 대비** | 중고생·어른을 위한 한국사능력검정시험 심화(1~3급) 대비 공간이에요. 아래에서 자세히 설명해요. |

### 🎓 한국사능력검정시험 심화 대비 (중고생·어른용)

| 기능 | 내용 |
| --- | --- |
| 📘 **개념 노트** | 10개 단원(선사·고조선 → 삼국 → 남북국 → 고려 → 조선 전기 → 조선 후기 → 근대 → 일제 강점기 → 현대 → 주제사)을 정리했어요. 주제마다 **📖 흐름 이야기**(왜 일어났고 어떻게 이어졌는지 강의하듯 풀어 쓴 글), **📌 핵심 정리**, **💡 시험 포인트·함정**, **🔤 용어 풀이**, 관련 **사진**이 있고, 단원 끝에는 **📜 대표 사료 읽기**(현대어 사료 → 정답과 단서 펼쳐 보기)가 있어요. 왕별 업적·여러 나라 비교·개헌 일람 같은 정리 표와 ‘핵심 정리만 보기’ 전환도 있어요. |
| 📖 **역사 사전** | 개념 노트에서 **밑줄 친 낱말**(굵은 글씨)을 누르면 팝업이 열려요. 진대법·광개토대왕·귀주 대첩·대동법·갑신정변·신간회처럼 핵심 낱말 426개는 **한 줄 요약, 강의하듯 풀어 쓴 자세한 이야기, 시험 포인트·함정, 함께 보면 좋은 낱말**과 관련 사진을 보여 주고, 그 낱말이 나오는 **암기 카드**와 **관련 문제 바로 풀기** 버튼도 있어요. 사전 항목이 없는 낱말은 용어 풀이·노트 문장·암기 카드를 모은 간단 풀이가 열려요. 팝업 안에서 다른 낱말로 옮겨 가고 되돌아올 수 있고, 학습 홈의 ‘📖 역사 사전’에서 낱말을 찾아보거나 단원별로 모아 볼 수 있어요. |
| ✏️ **기출 유형 문제** | 사료를 읽고 푸는 5지선다 204문제(단원마다 20문제 이상)를 담았어요. 고르는 즉시 **보기마다 왜 맞고 틀린지** 해설이 나와요. 순서 나열형과 문화유산을 설명으로 알아맞히는 문제도 있어요. |
| ❗ **오답 노트** | 틀린 문제가 자동으로 모이고, 두 번 연속 맞히면 빠져요. |
| 🗂️ **빈출 연도·키워드 암기 카드** | 단원별 189장이에요. 앞면을 보고 떠올린 뒤 뒤집어 확인해요. ‘다시 볼래요’를 누른 카드는 ‘헷갈리는 카드’로 모아 복습하고, ‘알아요’를 누르면 빠져요. 뒷면(설명)을 먼저 보는 모드도 있어요. 키보드: 스페이스 = 뒤집기, 1 = 다시 볼래요, 2 = 알아요. |
| 📝 **실전 모의고사** | 실제 시험처럼 50문항·80분이고, 단원별 출제 비율을 반영해 매번 새로 뽑아요. 제출하면 점수와 급수(1급 80점 이상), 단원별 결과, 틀린 문제 해설을 보여 줘요. 중간에 나가도 이어서 풀 수 있어요. |

문제는 기출 유형을 참고해 새로 만든 연습 문제예요. 실제 시험 일정과 접수는 국사편찬위원회 한국사능력검정시험 누리집에서 확인하세요.

### 가족 모두 함께
- **대원 등록**: 가족 한 명 한 명이 이름과 캐릭터를 골라 각자 기록을 쌓아요(최대 8명).
- **난이도**: 🌱 쉬움(7~9살 추천)은 쉬운 말과 쉬운 문제, 🌳 보통(10살 이상 추천)은 더 자세한 이야기와 문제가 나와요. 🎓 심화(중고생·어른)는 이야기가 🎓 어른용으로 열리고, 퀴즈는 어른용 문제 위주로 나오며, 화면 말투와 글꼴도 차분해져요(홈 맨 위에 한능검 심화 대비 안내). 대원마다 따로 정할 수 있고, 대원 화면에서 언제든 바꿀 수 있어요. 이야기 수준은 난이도와 상관없이 이야기 화면에서 언제든 바꿀 수 있어요.
- **🔊 읽어 줘**: 브라우저의 음성 합성 기능으로 이야기와 문제를 소리 내어 읽어 줘요. 글을 읽기 어려운 동생도 함께할 수 있어요.
- 효과음, 꽃가루 축하 효과가 있고, 오른쪽 위 🔊 버튼으로 효과음을 끌 수 있어요.

## 실행 방법

설치할 것이 없어요. `index.html` 파일을 브라우저로 열면 바로 시작돼요.

```bash
# 또는 간단한 웹 서버로 열기
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 휴대폰에서 바로 열기 (GitHub Pages, 무료)
GitHub Pages는 무료 계정에서 **공개 저장소**만 지원해요.

1. 저장소 **Settings → General** 맨 아래 **Danger Zone → Change repository visibility → Make public**
2. **Settings → Pages**에서 **Source**를 `Deploy from a branch`로 두고, 배포할 브랜치와 `/ (root)` 폴더를 골라 **Save**
3. 1~2분 뒤 `https://<사용자이름>.github.io/korean_history/` 주소로 접속해요. 이후에는 브랜치에 올린 내용이 자동으로 반영돼요.

**홈 화면에 앱처럼 추가하기**
- 아이폰(사파리): 사이트를 열고 아래쪽 **공유 버튼(네모에 위쪽 화살표)** → **홈 화면에 추가**
- 안드로이드(크롬): 사이트를 열고 오른쪽 위 **⋮** → **홈 화면에 추가**(또는 **앱 설치**)

범이 얼굴 아이콘과 ‘역사 탐험대’라는 이름으로 홈 화면에 나타나고, 주소창 없이 앱처럼 열려요.

## 내용 고치기·더하기

학습 내용은 한국사는 `js/data.js`, 세계사는 `js/world.js`에 모여 있어요. 두 파일의 구조는 같고, 세계사 쪽 이름에는 `WORLD_`가 붙어요(`WORLD_ERAS`, `WORLD_QUESTIONS` …).

- **시대 이야기**: `ERAS`의 `slides`에 `easy`(쉬움)와 `normal`(보통) 설명을 함께 적어요.
- **사진**: `js/era-images.js`의 `ERA_PHOTOS`에 `{ id, file, caption, author, license, license_url, source }`를 추가하고, `SLIDE_PHOTOS`의 시대 id 아래 슬라이드 순서대로 사진 id를 적어요(첫 번째가 큰 사진, 2~3장 권장). 카드 사진은 `CARD_PHOTOS`에 `카드 id: 사진 id`로 적어요. 다른 폴더(img/notes 등)의 사진도 그대로 쓸 수 있어요. 사진 목록이 없는 슬라이드·카드는 예전처럼 이모지·그림으로 보여요.
- **비교 상자**: 시대마다 `compare`에 다른 쪽(한국사↔세계사) 시대의 `era` id와 이야기를 적어요.
- **퀴즈 문제**: `QUESTIONS`에 추가해요. `level: 1`은 모든 대원, `level: 2`는 보통 대원에게만 나와요. 객관식은 `choices`의 **첫 번째 보기가 정답**이고, 화면에서는 보기 순서가 섞여서 나와요. 시대마다 `level: 1` 문제가 5개 이상 있어야 해요.
- **카드**: `CARDS`에 추가해요. `emoji`로 그림을 정하거나, `art: true`로 두고 `js/art.js`에 같은 `id`로 SVG 그림을 넣어요.
- **심화 문제**: `js/exam-q1.js`~`js/exam-q3.js`의 `EXAM_QUESTIONS`에 추가해요. `o`는 `[보기, 해설]` 5쌍이고 **첫 번째가 정답**이에요. 화면에서는 문제 id에 따라 정해진 순서로 섞여 나와요. 단원별 문제 수는 `js/exam.js`의 모의고사 출제 수(`weights`)보다 많아야 해요.
- **역사 사전**: `js/exam-dict1.js`~`js/exam-dict4.js`의 `EXAM_DICT`에 `{ id, term, unit, kind, when, aliases, summary, story, points, related, img }`를 추가해요. 노트의 `**굵은 낱말**`이 `term`·`id`·`aliases` 중 하나와 같으면(띄어쓰기, 『』, 괄호 속 덧붙임은 무시) 그 낱말을 눌렀을 때 이 항목이 열려요. 같은 이름이 여러 단원에 있으면 `id`를 `천리장성(고구려)`처럼 괄호로 구분하고, 보고 있는 단원의 항목이 먼저 열려요. `story`에서도 `**굵게**` 쓴 낱말은 누를 수 있어요.
- **어른용 깊이 읽기**: `js/deep/<시대 id>.js` 하나에 `(window.DEEP = window.DEEP || {})['<시대 id>'] = { slides, debates, sources, shadows, quiz, cards }`를 적어요. `slides`는 그 시대 `slides`와 같은 개수·순서·`title`로 `{ title, lead, deep: [문단…] }`, `debates`는 `{ q, views: [[입장, 설명]…], now }`, `sources`는 `{ from, text, read }`, `shadows`는 `{ title, text }`, `quiz`는 퀴즈 문제와 같은 형식(`era`·`level`은 자동으로 붙음, 심화 대원에게만 나옴), `cards`는 `{ 카드 id: [문단…] }`이에요. 글 안에는 곧은 따옴표(' ") 대신 ‘ ’ “ ” 『 』를 써요.
- **유튜브 영상**: `js/videos.js`의 `VIDEOS`에 `{ id, t, ch, len }`(유튜브 영상 id·제목·채널·길이, 영어 영상은 `en: true`)를 적어요. `era.<시대 id>.all`은 시대 전체, `era.<시대 id>.slides`는 슬라이드 순서대로, `nation.<이야기 id>`, `exam.<단원 id>`예요. 영상을 넣기 전에 `https://www.youtube.com/oembed?format=json&url=https://www.youtube.com/watch?v=<id>`가 200을 돌려주는지(있고 퍼가기 허용인지) 확인해요.
- **암기 카드**: `js/exam-flash.js`의 `EXAM_FLASH`에 단원 id별로 `[앞면, 뒷면]`을 추가해요. 같은 단원 안에서 앞면 글자가 겹치면 안 돼요.
- **나라별 세계사**: 나라는 `js/nations-*.js`의 `NATIONS`에, 사진은 같은 파일의 `NATION_IMAGES`에 추가하고 `js/nations.js`의 `NATION_ORDER`에 나라 id를 넣어요. 나라마다 `episodes`(이야기)에는 `hook`(궁금증 질문), `easy`·`normal`(아이용), `deep`(어른용, 문단 배열), `twist`(반전), `today`(지금과 연결), `korea`(같은 때 우리나라 — 한국사 시대 id와 글), `img`(사진 id)를 적어요. 퀴즈(`quiz`)는 위 퀴즈 문제와 같은 형식이고 `level: 1` 문제가 6개 이상 있어야 해요. 관련 카드는 `cards`에 세계사 카드 id를 적어요.
- **순서 맞추기 사건**: `EVENTS`에 추가해요. 기원전 연도는 음수로 적어요(예: 기원전 2333년 → `-2333`). 쉬움 단계는 시대 이름표를 힌트로 쓰기 때문에, 각 시대의 사건 연도가 다음 시대의 사건보다 앞서야 해요. `when`에 ‘약’이나 ‘무렵’이 들어간 사건은 100년 안쪽의 다른 사건과 함께 나오지 않아요.

## 알아 두세요

- 탐험·퀴즈의 역사 내용은 초등학교 사회 교과 수준, 심화 학습은 한국사능력검정시험 심화 범위로 정리했어요. 연도와 해석은 자료에 따라 조금씩 다를 수 있어요.
- 사이트 이름이 ‘범이의 한국사 탐험대’에서 ‘범이의 역사 탐험대’로 바뀌었지만, 이전에 쌓은 학습 기록은 그대로 이어져요.
- 학습 기록은 사용 중인 기기의 브라우저(localStorage)에만 저장돼요. 다른 기기와는 공유되지 않고, 브라우저의 사이트 데이터를 지우면 기록도 지워져요.
- 나라별 세계사의 국기는 이모지로 보여 줘요. Windows PC에서는 국기 대신 영문 두 글자(예: CN, JP)로 보일 수 있어요. 휴대폰과 Mac에서는 국기로 보여요.
- 글꼴(Jua, Gowun Dodum)은 Google Fonts에서 불러와요. 인터넷이 없으면 기기의 기본 글꼴로 보여요.
