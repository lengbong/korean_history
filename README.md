# 🐯 범이의 한국사 탐험대

아이들과 가족이 함께 즐기며 배우는 한국사 학습 웹사이트예요.
호랑이 탐험대장 **범이**와 함께 선사 시대부터 오늘날의 대한민국까지 시간 여행을 떠나요!

## 이렇게 놀아요

| 놀이 | 내용 |
| --- | --- |
| 🗺️ **시대 탐험** | 9개 시대(선사 → 고조선 → 삼국 → 남북국 → 고려 → 조선 → 근대 → 일제 강점기 → 대한민국)를 정거장처럼 따라가며 이야기를 읽어요. 끝까지 읽으면 **탐험 도장**과 카드를 받아요. 핵심 낱말 뒤집기 카드와 재미있는 사실도 있어요. |
| ❓ **역사 퀴즈** | 시대별 5문제 또는 모든 시대 섞어서 10문제. OX 퀴즈와 객관식 문제가 나오고, 문제마다 해설이 나와요. 3문제 이상 맞히면 카드 1장, 만점이면 2장! |
| 🃏 **카드 도감** | 인물·문화유산·상징 카드 47장을 모아요. 카드를 누르면 업적과 ‘알고 있니?’ 이야기가 나와요. |
| 🔢 **순서 맞추기** | 역사 사건 카드를 옛날 일부터 차례대로 놓아요. 모두 맞히면 보너스 카드! |

### 가족 모두 함께
- **대원 등록**: 가족 한 명 한 명이 이름과 캐릭터를 골라 각자 기록을 쌓아요(최대 8명).
- **난이도**: 🌱 쉬움(7~9살 추천)은 쉬운 말과 쉬운 문제, 🌳 보통(10살 이상 추천)은 더 자세한 이야기와 문제가 나와요. 대원마다 따로 정할 수 있어요.
- **🔊 읽어 줘**: 브라우저의 음성 합성 기능으로 이야기와 문제를 소리 내어 읽어 줘요. 글을 읽기 어려운 동생도 함께할 수 있어요.
- 효과음, 꽃가루 축하 효과가 있고, 오른쪽 위 🔊 버튼으로 효과음을 끌 수 있어요.

## 실행 방법

설치할 것이 없어요. `index.html` 파일을 브라우저로 열면 바로 시작돼요.

```bash
# 또는 간단한 웹 서버로 열기
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### GitHub Pages로 공개하기
1. GitHub 저장소의 **Settings → Pages**로 이동해요.
2. **Source**에서 `Deploy from a branch`를 고르고, 배포할 브랜치와 `/ (root)` 폴더를 선택해 저장해요.
3. 잠시 뒤 `https://<사용자이름>.github.io/korean_history/` 주소로 접속할 수 있어요.

## 파일 구성

```
index.html      화면 뼈대
css/style.css   디자인 (색동 줄무늬와 오방색을 살린 밝은 테마)
js/data.js      시대 이야기, 퀴즈 문제, 카드, 순서 맞추기 사건 데이터
js/art.js       문화유산 카드 그림(SVG): 고인돌, 첨성대, 다보탑, 태극기 등
js/app.js       화면 이동, 대원 관리, 퀴즈·카드·순서 맞추기 로직
```

## 내용 고치기·더하기

모든 학습 내용은 `js/data.js`에 모여 있어요.

- **시대 이야기**: `ERAS`의 `slides`에 `easy`(쉬움)와 `normal`(보통) 설명을 함께 적어요.
- **퀴즈 문제**: `QUESTIONS`에 추가해요. `level: 1`은 모든 대원, `level: 2`는 보통 대원에게만 나와요. 객관식은 `choices`의 **첫 번째 보기가 정답**이고, 화면에서는 보기 순서가 섞여서 나와요. 시대마다 `level: 1` 문제가 5개 이상 있어야 해요.
- **카드**: `CARDS`에 추가해요. `emoji`로 그림을 정하거나, `art: true`로 두고 `js/art.js`에 같은 `id`로 SVG 그림을 넣어요.
- **순서 맞추기 사건**: `EVENTS`에 추가해요. 기원전 연도는 음수로 적어요(예: 기원전 2333년 → `-2333`).

## 알아 두세요

- 역사 내용은 초등학교 사회 교과 수준으로 정리했어요. 연도와 해석은 자료에 따라 조금씩 다를 수 있어요.
- 학습 기록은 사용 중인 기기의 브라우저(localStorage)에만 저장돼요. 다른 기기와는 공유되지 않고, 브라우저의 사이트 데이터를 지우면 기록도 지워져요.
- 글꼴(Jua, Gowun Dodum)은 Google Fonts에서 불러와요. 인터넷이 없으면 기기의 기본 글꼴로 보여요.
